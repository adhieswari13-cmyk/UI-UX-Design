# UI/UX Training – 10 Days Challenge

This repository contains the UI/UX design tasks completed as part of my
10-day UI/UX training program.

The projects were designed and developed using HTML, CSS, and Bootstrap.
The training focused on creating responsive and user-friendly web interfaces.

## Technologies Used
- HTML
- CSS
- Bootstrap

- Instagram Login Page

- Netflix Landing Page
- Amazon Product Page
- Spotify Music Player
- E-commerce Home Page

- Travel Booking Landing Page
- Portfolio Website
- Admin Dashboard
- Banking Dashboard
- Food Delivery App

- Student Portal Dashboard
